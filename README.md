# DownV

A simple and modern command-line media downloader.

> **Note:** DownV is currently under active development. Features will be added incrementally.

## Installation

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

Install the project in editable mode:

```bash
pip install -e .
```

## Usage

```bash
downv
```

Or via the module:

```bash
python -m downv
```
